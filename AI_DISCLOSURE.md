# AI-Assisted Development

## How it started

I've been using KDE and Linux for many years, and **KDocker** was always one of those small utilities I couldn't do without.

When openSUSE Tumbleweed moved to KDE Plasma 6.8 and dropped the X11 session, I needed a replacement that would work with Wayland. I found [KWin Minimize2Tray](https://github.com/luisbocanegra/kwin-minimize2tray) by Luis Bocanegra and decided to fork it, adding the features and improvements I wanted for my daily workflow.

## About the AI part

**Yes, this fork is largely vibe coded.** I use AI coding tools to help implement features, investigate problems, fix bugs, and improve the code.

The ideas, requirements, and development direction come from me. I review and test the results on my KDE Plasma setup, although that doesn't mean every change is perfect or that the code has undergone a full security audit.

AI makes development faster, and with less spare time for coding these days, that's a pretty useful advantage.

Regardless of how the code is written, **I take responsibility for what I publish.**
